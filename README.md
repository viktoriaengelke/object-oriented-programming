# object-oriented-programming
Структуры данных:
BinTree - Реализация бинарного дерева.

BinaryTreeSearch - Реализация бинарного дерева поиска (BST) с операциями вставки и поиска.

List - Реализация связного списка.

Объектно-ориентированное программирование:
OOP_Array - Реализация динамического массива с использованием принципов ООП (перегрузка операторов, конструкторы/деструкторы).

OOP_Array-template - Шаблонная (обобщенная) реализация динамического массива.

OOP_BoolMatrix - Класс для работы с булевыми матрицами.

OOP_Complex - Класс для работы с комплексными числами (перегрузка арифметических операций).

OOP_classBV - Реализация класса битового вектора (Bit Vector).

OOP_classSet - Реализация класса множества с поддержкой основных операций над множествами.

Полиномы:
Polinom - Реализация класса для работы с многочленами (полиномами).

Polinom-Template - Шаблонная реализация класса многочленов для работы с различными типами данных.
